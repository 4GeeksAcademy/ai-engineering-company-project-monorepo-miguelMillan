# TrackFlow API Service

Servicio backend minimo para inicializar la capa `services/`.

## Endpoints
- `GET /health` -> devuelve estado del servicio.

## Ejecutar en local
```bash
cd services/api
npm run dev
```

## Nota
El servidor escucha en `0.0.0.0:8080` por defecto para compatibilidad con Codespaces.
