# TrackFlow Website

Aplicacion web corporativa publica de TrackFlow.

## Stack
- React + TypeScript + Vite
- Tailwind CSS v4 (via `@tailwindcss/vite`)

## Ejecutar en local
```bash
cd uis/website
npm install
npm run dev
```

La app queda disponible por defecto en `http://0.0.0.0:5173` para compatibilidad con Codespaces.

## Build
```bash
npm run build
```
