# Project Brief — TrackFlow

## Negocio
TrackFlow es una empresa de logistica de ultima milla y gestion de almacenes que opera en Los Angeles (EE.UU.) y Zaragoza (Espana). Da servicio a marcas e-commerce cubriendo almacenamiento, preparacion de pedidos, envio final y devoluciones.

## Problema que resuelve
Las marcas clientes venden bien, pero no suelen tener capacidad operativa para ejecutar logistica con consistencia en dos paises. TrackFlow asume esa complejidad:
- Inventario distribuido en dos almacenes.
- Seleccion y coordinacion de transportistas.
- Seguimiento de envios y resolucion de incidencias.
- Gestion de devoluciones con criterios operativos y de coste.

## Dolor actual interno
El contexto actual describe una operacion con alta carga manual y sistemas desconectados:
- Sistemas de almacen distintos entre paises y sin visibilidad global.
- Asignacion de transportista manual.
- Validacion de devoluciones caso por caso.
- Atencion al cliente con alto volumen de consultas repetitivas.
- Reportes ejecutivos manuales y con retraso.

## Objetivos del proyecto
Construir una base tecnica progresiva para la transformacion digital de TrackFlow:
1. Estandarizar modelos de datos y utilidades de negocio en TypeScript.
2. Desplegar interfaces separadas para web publica y operacion interna.
3. Preparar servicios backend para exponer capacidades (salud, APIs, integraciones).
4. Introducir reglas y memoria operativa para mejorar continuidad de trabajo del agente.

## Propuesta de valor
El proyecto busca reducir errores operativos y tiempo de decision mediante:
- Visibilidad centralizada de inventario y operaciones.
- Mejor asignacion de transportistas por coste, velocidad y confiabilidad.
- Fundamentos para automatizar devoluciones y soporte.
- Mejor trazabilidad de progreso tecnico y decisiones por medio de un banco de memoria y reglas de agente.
